# Job-Search Agent Bot

A Telegram bot that acts as an automated job-search agent.

> The source code of this project is private. This page describes what it does and how it is run.

## What it does
- Searches for jobs automatically on behalf of the user.
- Integrates with the user's email account.
- Uses timers to run its work on a schedule.
- Supports different LLM models.

## How it is run
- Runs as a managed service on a Linux server.
- Delivered and handed over with project documentation.

## Context
Built at Arika (2024 - 2026) as one of five production services I delivered and handed over.
